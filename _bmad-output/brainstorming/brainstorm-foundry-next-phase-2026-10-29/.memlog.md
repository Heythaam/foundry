- (decision) Stance: Facilitator. Techniques: SCAMPER, Job to Be Done, Empathy Map, Kill the Crown Jewel
- (idea) Web dashboard (auto-opens on foundry pro): live phase progress, streaming agent output, inline checkpoint approval with diff view instead of "
- (idea) Combine AgentRunner + test gate: agent runs tests mid-implementation, self-corrects on failure, one continuous loop instead of implement → hand off → check → retry
- (idea) ATC-style readback at every checkpoint: human must confirm key facts before phase advances (e.g. 'confirming PRD with 12 FRs, test runner: npm test') — prevents rubber-stamping, creates audit trail of conscious decisions
- (idea) Universal agent protocol: drop foundry-agent.sh in the repo, Foundry calls it with story path + waits for exit 0. Agent is a black box — works with vim macros, internal tools, custom LLM wrappers. Abstraction becomes a Unix pipe.
- (idea) Export epics/stories to Jira/Linear/Notion: each epic → project, each story → ticket with AC pre-filled, PRD → project brief. Foundry bootstraps the entire project tracker, not just the codebase.
- (idea) Eliminate brainstorm phase: start directly at PRD. Human's original idea IS the brainstorm. Pre-flight catches gaps. Pipeline loses nothing structural, saves a redundant checkpoint.
- (idea) Agent-driven intent model: agent proposes next move ('creating src/api.py with 3 endpoints'), Foundry validates against architecture constraints before acting. Human approves intent, not file edits. Foundry as guardrail, not director.
- (technique) started Job to Be Done
- (insight) JTBD: user hires Foundry to replace their own discipline — the glue between ChatGPT (PRD), Copilot (code), GitHub (repo) that was failing. Core job: idea to working code without losing a week to setup/planning overhead.
- (insight) Discipline breaks at planning-to-implementation handoff: PRD + arch exist but no forcing function to start coding. Week lost in gap between 'I know what to build' and 'first line of code written.'
- (insight) CLI visuals that matter: ones that fill silence with signal and make next step feel inevitable. 'Here's what happens next' summaries + single-keypress proceed > progress bars (polish). The job is closing the void between phases, not decoration.
- (insight) Multi-tool job reframe: Epic 9 isn't about compatibility, it's about not becoming the gap. Momentum is the job. If Foundry only runs on Claude Code, it breaks when someone's env differs. Implication: not a full abstraction layer — seam already exists, add 1-2 concrete impls + docs + a good error message.
- (technique) started Empathy Map
- (idea) Says quadrant: failure vocabulary is vague + spatial ('stopped', 'got stuck', 'lost track') — they describe absence of outcome, not mechanism. Success = silence; they open the PR, Foundry disappears into the result.
- (insight) Thinks quadrant: 'I hope I don't have to fix this' — anxiety about whether the escape was real. Accountability never transfers, only labor. If Foundry fails, it's still on them. They're half-present elsewhere while monitoring for the sound of breaking.
- (idea) Does quadrant: tab away + check every 30s in a loop. On success: run tests, skim diff for obvious wrong, open PR — never read code story-by-story. On failure: reread their own spec looking for what THEY said wrong, edit spec, retry.
- (insight) Spec is the control surface. UX priority: transparency at spec-interpretation step before run, not during run. 'Spec-in, result-out, maximum transparency at the parse moment.' Agent tool is interchangeable; spec is not — confirms AgentRunner as right abstraction seam.
- (insight) Feels quadrant: relief, not pride. Relief = anxiety was real the whole time, they were passengers. Target feeling is AUTHORSHIP — 'my project, Foundry did the grunt work.' Spec transparency before the run is the mechanism: see Foundry interpret your intent, approve it, shape it → the PR feels like yours.
- (technique) started Kill the Crown Jewel
- (decision) Crown Jewel identified: the checkpoint — the handshake between human intent and machine execution. Defines what makes Foundry, Foundry.
- (idea) Kill the Crown Jewel result: checkpoint migrates upstream to spec interpretation. Spec editor shows how Foundry parsed your intent before any code runs — you approve interpretation, not output. Run is then uninterrupted. Stronger authorship: control at spec layer (where instinct already goes) not mid-execution (wrong moment, already committed).
- (decision) Epic 8 MoSCoW — Must: spec interpretation readback, named failure states. Should: phase signal (summary + keypress). Won't: web dashboard. North star: authorship not relief; spec is the control surface.
- (decision) Epic 9 MoSCoW — Must: don't be the gap (1-2 concrete AgentRunner impls + error message + docs). Should: foundry-agent.sh unix pipe abstraction. Won't: self-correcting agent loop.
- (insight) Synthesis: all four techniques converged on one place — the spec interpretation moment. SCAMPER (checkpoint migrates upstream), JTBD (spec is the control surface), Empathy Map (authorship not relief), Kill the Crown Jewel (crown jewel migrates not dies). Epic 8 is about making that moment visible. Epic 9 is about not breaking it when the runner changes.
