topic: Epic 9: Multi-tool / AgentRunner Compatibility — Aider, Codex CLI, shell runner, contributor docs
updated: 2026-10-30T09:44
---

- (capability) CAP-1: Foundry runs end-to-end with at least two agent tools beyond Claude Code. Success: foundry pro completes with AiderRunner and a second distinct runner; both pass the integration test harness used for ClaudeCodeRunner.
- (capability) CAP-2: Runner-not-found failure produces actionable error, not a traceback. Success: when configured runner binary is missing, stderr names the tool, the config key, and the install command; no Python traceback reaches the user.
- (capability) CAP-3: A repo containing foundry-agent.sh acts as a valid AgentRunner when agent.runner='shell'. Success: script receives story path as ; exit 0 = success, non-zero = failure; any tool that can be scripted can be wired in without writing Python.
- (capability) CAP-4: AgentRunner contributor documentation is sufficient to ship a new runner without reading source. Success: a contributor with no prior Foundry knowledge can add a runner by following the doc alone.
- (constraint) The AgentRunner protocol in foundry/agent.py must not change — new runners implement the existing interface. The seam is correct; this epic adds plugs, not a new seam.
- (constraint) Runner selection is always explicit (no auto-detection from PATH). Default runner remains Claude Code for backward compatibility.
- (constraint) New runners must pass the same integration test harness as ClaudeCodeRunner before merging.
- (decision) Non-goals: self-correcting agent loop (deferred), agent output normalization, runner auto-detection, plugin marketplace/registry.
- (decision) Priority runner order: Aider as FR-9.1 (more stable CLI contract), OpenAI Codex CLI as FR-9.2 — but needs spike to confirm before epic is scheduled (OQ-9.1).
- (decision) Stories: 9.1 AiderRunner, 9.2 Codex CLI Runner, 9.3 Runner Config + Error, 9.4 Shell Runner (foundry-agent.sh), 9.5 Contributor Docs. Test target ~1020 from ~950.
- (event) Self-validate Pass 1 (Coherence): all 4 CAPs have intent+success; AgentRunner seam constraint is load-bearing (rules out interface changes); non-goals explicit. Pass 2 (Preservation): all PRD claims absorbed; OQ-9.1-9.4 carried as open questions.
- (event) stories.yaml written: 5 stories (9-1 AiderRunner, 9-2 CodexRunner, 9-3 runner config, 9-4 shell runner, 9-5 contributor docs). Validity check: ids unique, no zero-padding, no status field, done_checkpoint=true on 9-5 per PRD. All required fields present.
