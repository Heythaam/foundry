- (technique) started Chaos Engineering

- (idea by user) Chaos: human approves internally inconsistent PRD, Foundry builds it faithfully but wrong - need contradiction detector as hard stop before architecture, resolution logged as first-class decision
- (idea by coach) Chaos: model version changes mid-run after crash/resume, codebase has style uncanny valley - need model pinning in foundry.lock or post-build consistency pass

- (idea by coach) Chaos: info loss between pipeline stages - brainstorm has 13 dirs, PRD silently covers 9 - need traceability matrix with explicit mapping between stages, human decides what to drop
- (idea by user) Chaos: GitHub rate limit mid-run, retry loop treats infra failure as code failure, LLM corrupts working code - need 3 failure categories: code (LLM fixes), infra (pause+wait), environment (hard stop)
- (insight) Principle: external failure is the normal case not the edge case - Foundry talks to 4+ services and must treat partial outages as routine
- (technique) started Kill the Crown Jewel
- (idea by user) Kill BMad planning reveals product split: Foundry Pro (full pipeline) vs Foundry Quick (skip to code, vibe coding with guardrails) - shared engine, lock file, CI/CD
- (insight) The crown jewel is foundry.lock + structured git history, not BMad - provenance and traceability are what make it Foundry, BMad is the most powerful mode not the only one
- (idea by user) Minimum viable Foundry Quick: (1) self-written spec as first checkpoint, (2) incremental logical commits not file dump, (3) tests non-negotiable before commit - these three separate it from raw LLM
- (insight) Core Foundry value proposition: structure (explicit contract), incrementality (navigable history), verification (tests required) - not the planning brain, not the deployment
- (insight) Build strategy: Foundry Quick is the MVP shipped first - proves core value without BMad dependency, Foundry Pro adds planning on top
- (technique) started Utopia vs Dystopia Split-Screen

- (insight) Principle: the audit trail is a weapon that cuts both ways - it proves diligence or proves negligence, Foundry must make rubber-stamping harder not easier
